# Security reports / 安全报告

## Report privately

For vulnerabilities such as unauthorized task execution, file access outside the allowed work copy, or credential exposure, use [GitHub's private vulnerability reporting form](https://github.com/mekoand/sub2sub/security/advisories/new). Sign in to GitHub to submit a report to the repository maintainer.

Include the affected version, operating system, Host/Client role, execution tool, expected boundary, and minimal reproduction using synthetic data. Do not put exploit details in public issues or PRs. Never include live invitations, tokens, account credentials, private project files, or unredacted task logs, even in a private report.

For ordinary setup and usage problems, see [troubleshooting](docs/troubleshooting.en.md) or [Issues](https://github.com/mekoand/sub2sub/issues). Include your version; check the [latest release](https://github.com/mekoand/sub2sub/releases/latest) for available fixes. This community-maintained project does not promise a response time or maintenance of every historical version.

## 私密报告

未经授权执行任务、越过工作副本范围访问文件、凭据泄露等安全问题，请使用 [GitHub 私密漏洞报告表单](https://github.com/mekoand/sub2sub/security/advisories/new)。登录 GitHub 后，报告会提交给仓库维护者。

请提供受影响版本、系统、Host/Client 角色、执行工具、预期边界，以及使用合成数据的最小复现。不要在公开 Issue 或 PR 中发布漏洞利用细节。即使是私密报告，也不要包含有效邀请码、Token、账号凭据、私有项目文件或未脱敏的任务日志。

普通安装和使用问题请查看[故障排查](docs/troubleshooting.md)或 [Issues](https://github.com/mekoand/sub2sub/issues)。反馈时注明版本，并在[最新发行版](https://github.com/mekoand/sub2sub/releases/latest)检查已有修复。社区维护项目不承诺固定响应时间或持续维护所有历史版本。
